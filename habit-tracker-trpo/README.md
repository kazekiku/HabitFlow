# HabitFlow

HabitFlow — это iOS-приложение для отслеживания привычек, построенное на современном SwiftUI и SwiftData. Приложение позволяет создавать привычки с настраиваемыми иконками и цветами, отмечать их выполнение, получать уведомления-напоминания, просматривать статистику прогресса и визуализировать достижения в календаре. Поддерживается учёт как полезных, так и вредных привычек с интуитивным интерфейсом и анимированными переходами.

## Структура проекта

### Основные файлы приложения

- **HabitFlowApp.swift** — точка входа в приложение (`@main`), настройка SwiftData контейнера и запрос разрешений на уведомления
- **ContentView.swift** — корневое представление с навигацией между вкладками (привычки, статистика, календарь) и управлением боковым меню

### Модели данных

- **Habit.swift** — модель привычки с использованием SwiftData (`@Model`), содержит логику частоты выполнения, проверки выполнения, расчёта серий (streak) и управления датами выполнения

### Представления (Views)

#### Основные экраны
- **HabitListView.swift** — список всех привычек с возможностью добавления, редактирования и удаления
- **StatisticsView.swift** — экран статистики с графиками прогресса, общими показателями и детальной аналитикой по привычкам
- **CalendarFullView.swift** — полноэкранный календарь с навигацией по месяцам и визуализацией выполнения привычек по дням

#### Компоненты интерфейса
- **MonthlyCalendarView.swift** — компактный месячный календарь с анимированной навигацией и цветовой индикацией выполнения привычек
- **HabitDetailView.swift** — детальная информация о привычке с возможностью редактирования
- **AddHabitView.swift** — форма создания новой привычки с выбором цвета, иконки, частоты и настройкой уведомлений
- **HabitRowView.swift** — ячейка привычки в списке с кнопкой выполнения и индикатором прогресса
- **SideMenuView.swift** — боковое выдвижное меню для навигации между разделами приложения

### Утилиты и вспомогательные файлы

- **NotificationManager.swift** — менеджер локальных уведомлений, запрос разрешений и планирование напоминаний о привычках
- **ColorHex.swift** — расширение `Color` для работы с HEX-цветами
